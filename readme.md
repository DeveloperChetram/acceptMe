# 😄 Just for Fun – "acceptMe?" Interactive Web Page

This is a quirky little web project made purely for fun using **HTML**, **CSS**, and **JavaScript**. It features a playful question:

> **"Do you love me?"**

Two buttons — **YES** and **NO** — are shown. But beware... the **NO** button plays hard to get. It literally runs away when you try to click it! 🏃‍♂️💨

- To explore JavaScript DOM manipulation and event handling
- To experiment with fun UI/UX behavior

## 💡 Features

- ✅ "NO" button escapes the mouse cursor like it's got trust issues 😆
- ✅ Fun and flirty design with smooth animations
- ✅ Fully responsive — works great on mobile too
- ✅ Code is beginner-friendly and easy to tweak

- **CSS3**
